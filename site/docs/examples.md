# See it in real apps

> Three made-up apps built with Lookup, each opening full screen. A church management app, a nonprofit sign-up and a church website builder.

Source: https://lookup.heresmychurch.com/docs/examples

Each example is a working app using the real widget and live data, in demo mode so nothing you share is sent. They open full screen on the homepage.

- [Kinship, a church management app](/#example/kinship): React with controlled inputs. Add a partner church and watch React's state fill in.
- [Harvest Table, a food pantry network](/#example/harvest): A plain HTML sign-up that registers churches as distribution sites, posting `church_id` with the form.
- [Steeple, a church website builder](/#example/steeple): Pick your church and a live website preview builds itself from its details.

## What each one shows

| Example | Shows |
|---|---|
| Kinship | React controlled inputs, `church-select` and `church-clear` events, the share panel |
| Harvest Table | `name` and `required` in a plain form, service times feeding distribution hours |
| Steeple | Filling a live preview, `<church-service-times>`, theming to a product's own look |

Every example uses `client="lookup-demo"`, so corrections are checked but never sent to Here's My Church.
