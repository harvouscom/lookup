# Example apps

> Made-up apps built with Lookup, using the real widget and live data. A church management app, a nonprofit sign-up and a church website builder.

Source: https://lookup.heresmychurch.com/docs/examples

Each one is a made-up app using the real widget and live data, in demo mode so nothing you share is sent. They open full screen on the homepage.

## What each one shows

| Example | Shows |
|---|---|
| Kinship | React controlled inputs, `church-select` and `church-clear` events, the share panel |
| Harvest Table | `name` and `required` in a plain form, service times feeding distribution hours |
| Steeple | Filling a live preview, `<church-service-times>`, theming to a product's own look |
| Kinship, shadcn version | `shadcn add` from the registry, `ChurchLookup` in a React Hook Form `FormField`, `ChurchConsent` |

Every example uses `client="lookup-demo"`, so corrections are checked but never sent to Here's My Church.
