# Lookup mark

A cursive lowercase "l" drawn as one thick stroke, an extension of the Here's My Church app icon, whose
cursive "h" is also a single stroke that runs off the edges of its tile.

- Tile: 64×64, corner radius 15, gradient `#43218A` to `#160B30` with a soft white highlight at the top left.
- Stroke: width 8.5, round caps, gradient `#F5EDFF` to `#D8B4FE` to `#B98AD6`. It enters from the left edge, rises
  into an open loop that stays inside the tile, comes down, and exits off the right edge. Every curve join is
  tangent, so the line has no corners, and the loop's counter is kept open so it reads at favicon size.
- Wordmark: "lookup" in lowercase Geist 600, tracking −0.02em, set beside the tile.

`mark.svg` is the source; `/favicon.svg` is a copy. Refine freely in a design tool, keeping the single
stroke and the edge bleed.
