How it works

Stop retyping church details

Lookup fills church forms from Here’s My Church, an open directory of 587,842 churches in 19 countries. Every app that uses it helps keep that data right.

  • church in dall Grace Community ChurchDallas, TX First Baptist DallasDallas, TX

    Search as you type

    Prefixes, typos and places like “church in dallas” all work, nearby churches first.

  • Street1420 Elm St ServicesSun 10:30 am Phone(214) 555-0142kept

    Fill your form

    Pick a church and empty fields fill in. Anything already typed is left alone.

  • Service timesSun 9:00Sun 10:30 Share this fix with the directory

    Share fixes back

    When someone corrects a detail, they can send it back to the directory with one checkbox.

Get started

Two ways in

Drop it in
One script tag, no build, any framework. It picks up Sensible UI and shadcn-style tokens with no setup.
Own the code
A shadcn registry adds a ChurchLookup built from Command and Popover, plus a hook. Works with React Hook Form.
<!-- Any page, no build. Sensible UI is optional: its tokens style the widget. -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@faith-tools/sensible-ui@1.7.0/dist/sensible-ui.min.css">
<script type="module" src="https://lookup.heresmychurch.com/element.js"></script>

<form>
  <church-lookup name="church_id" label="Your church"></church-lookup>
  <input name="city" data-hmc-field="city">
</form>
# Copies the component, a hook and the engine into your app
pnpm dlx shadcn@latest add https://lookup.heresmychurch.com/r/church-lookup.json

<FormField name="church_id" render={({ field }) => (
  <ChurchLookup {...field} client="my-app" onFill={setRecord} />
)} />
<Input {...form.register("city")} data-hmc-field="city" />
