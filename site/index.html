Stop retyping church details

Church tools keep asking people for the same details. Lookup fills them in from Here's My Church, an open directory of 587,842 churches in 19 countries. Because every pick comes from the same open directory, each app that uses Lookup helps keep church data accurate.

  • Search as you typePrefixes, typos and places like "church in dallas" all work, nearby churches first.
  • Fill your formPick a church and empty fields fill in. Anything already typed is left alone.
  • Share fixes backWhen someone corrects a detail, they can share it back to the directory, one checked box at a time.

See it in real apps

Three made-up apps using the real widget and live data. Each opens full screen, in demo mode, so nothing you share is sent.

Choose your path

One engine, two front doors. Drop the element into any page, or own the code in a React app.

<!-- Any page, no build. Sensible UI is optional: its tokens style the widget. -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@faith-tools/sensible-ui@1.7.0/dist/sensible-ui.min.css">
<script type="module" src="https://lookup.heresmychurch.com/element.js"></script>

<form>
  <church-lookup name="church_id" label="Your church"></church-lookup>
  <input name="city" data-hmc-field="city">
</form>
# Copies the component, a hook and the engine into your app
pnpm dlx shadcn@latest add https://lookup.heresmychurch.com/r/church-lookup.json

<FormField name="church_id" render={({ field }) => (
  <ChurchLookup {...field} client="my-app" onFill={setRecord} />
)} />
<Input {...form.register("city")} data-hmc-field="city" />

Drop it in. One script tag, no build, any framework. On a page using Sensible UI by Cam Pak, or any shadcn-style tokens, it matches your theme with no setup.

Own the code. A shadcn registry gives you a ChurchLookup built from Command and Popover, plus a hook and a share-fixes panel. It works with React Hook Form. See it in Kinship.
