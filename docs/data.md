Lookup reads Here's My Church's reviewed listings and re-syncs changed regions every 5 minutes. Searches aren't logged, and approximate location is only used in memory to rank nearby churches.

:::note Why fewer churches than Here's My Church shows?
Its map counts every listing, about 655,000. Lookup leaves out about 68,000 that have no real name yet, such as "Unnamed church", since nobody can find those by typing. Once a listing gets a name on Here's My Church, the next sync adds it.
:::

## Sharing fixes back

When someone changes a detail Lookup filled, the widget offers to share it. Every change starts unchecked, says whether it goes live or waits for a moderator, and nothing is sent until they choose Share. Your form's own submit is never blocked.

| Field | Where | Review |
|---|---|---|
| Service times, denomination, languages, ministries | Everywhere | Live on one vote |
| Phone | US and Canada | Live on one vote |
| Website | Everywhere | Waits for a moderator |
| Name | Coming soon | Will wait for a moderator |
| Address | US | Waits for a moderator |
| Email, pastor name | Not accepted | Personal details in a host's form can't go live |

Turn the offer off with `contribute="off"`, or cancel the `church-contribute` event to send changes yourself.
